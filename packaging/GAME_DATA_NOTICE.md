GAME DATA NOTICE
================

This is a very early alpha of the Replay Revival Godzilla: Save the Earth recompilation project. The release does not include Xbox disc content, extracted game files, textures, models, audio, video, maps, saves, or other game data.

To use it, choose your own legally obtained Xbox disc image (.iso) or extracted game folder in the launcher. An image is unpacked once into the launcher's data folder; it is only read, never modified or uploaded. The project does not provide, host, or authorize redistribution of copyrighted game data. Do not place disc images or extracted game content in this release archive.

The launcher keeps user-specific data under its writable `data` directory after first run.
