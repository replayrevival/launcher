Everything in v0.1.3 is in it, plus:

GAME (build c370)
- Fixes a rare freeze: the window stayed open but the game stopped drawing frames. The game now releases the
  vblank signal itself if a frame-timing hand-off is missed. No other change to how the game plays.

KNOWN ISSUES
- Mechagodzilla 3's back missiles are invisible while they fly; the launch flash and the hits show.
- A rare crash while loading, seen on slow systems. Still being investigated.
- A possible rare stall in the game's DirectSound audio code was seen in two test runs. Not reproduced, not fixed.
- Patch mods are prepared but not yet loaded by the game. Work continues.

The launcher itself is unchanged from v0.1.3.
