Everything in v0.2.1 is in it, plus:

GAME (build c431)
- Retexture any monster. Texture packs you install from the launcher's Mods tab now work in the game:
  the game reads them from the mods folder and follows the Mods tab's on/off switch and order.
  (Before, a pack only worked when it was copied into the game's own texturepacks folder.)
- Export the game's own textures as named PNGs from your game folder or disc image, edit them, build a pack
  in one command and install it. The step-by-step guide is docs/MODDING.md ("Retexture a monster").

LAUNCHER
- The Mods tab shows what kind of mod each one is: "Texture pack" (and "Sound pack" for the sound packs that come
  later).
- The modding guide (docs/MODDING.md) is rewritten: start here, a walkthrough per mod type, every setting you can
  change (generated from the launcher's own settings file), troubleshooting and a "what's changed for modders" list.

KNOWN ISSUES
- Unlimited draw distance can still show buildings popping in and out at the far skyline (not fixed, not verified either way).
- In Tokyo a UFO can leave the playing area (out of bounds). Not fixed yet.
- The announcer's "RAGE" voice line: in our test fights an announcer voice plays about a second after a monster enters
  rage, but we have not been able to confirm that it says "RAGE". Not fixed yet.
- Retexturing works for the pictures the game draws as textures. Every monster has one skin set (colour and bump map);
  menu name plates are not power-of-two pictures and may look stretched if you change their shape.
- Typing a name was tested with a virtual keyboard path only, not with a physical keyboard.
- Playing from a disc image was tested with images made from an extracted game folder, plain and with a video
  partition in front. Images dumped from a real disc have not been tested yet.
- A rare crash while loading, seen on slow systems. Still being investigated.
- A possible rare stall in the game's DirectSound audio code, seen in two test runs. Not reproduced, not fixed.
- With the in-game menu open the picture is redrawn only when something changes, so it can look choppy in video.
- Exclusive fullscreen is less tested than the other modes.
- A real physical controller has not been tried with the in-game menu (the tests used a virtual one).
  Only Xbox controllers have been tested. Windows only.

PACKAGE
- Same files as v0.2.1, including ste_overlay.dll (the in-game menu).
