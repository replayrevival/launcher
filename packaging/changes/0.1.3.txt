Everything in v0.1.2d is in it, plus:

MODS (new tab)
- Install a mod from a .zip or a folder (buttons, or drag it onto the launcher window). Turn mods on and off,
  change their load order (the one lower in the list wins when two change the same file) and remove them.
  Mods are kept in data\mods\. Your game files are never changed; the game loads the mods itself.
- Each mod says whether it works with your copy of the game. A mod made for another version of the game, one that
  needs another mod, or one that does not work together with another is marked, and the game skips it.
- Safety: a zip with unsafe file paths, a password or a damaged file is refused with a plain message, nothing is
  half-installed. Removing a mod moves it to data\mods\_removed\, so you can get it back.

- Patch mods: a mod can ship small patches instead of game files. The launcher checks your own game file against the
  patch, builds the changed file into the mod's own folder (your game files stay untouched) and tells you in plain
  words if a mod was made for a different version. PLAY prepares them first; there is also a PREPARE PATCHES button.
  (The game build does not load the built files yet; that comes in a later version.)

CONTROLLERS
- New "Button prompts" setting: Auto (match my controller), Xbox, Original Xbox (Black and White buttons) or
  PlayStation. The launcher's own button hints and the button names on the remap screen follow it. The choice is
  saved in the game's settings and passed to the game when it starts.

BUTTON PICTURES
- The hint bar and the remap screen show real button pictures that follow "Button prompts": Xbox, Original Xbox
  (coloured A/B/X/Y, round Black and White buttons) or PlayStation; Auto follows the connected controller.
  Switch and other pads, and the keyboard, still show text key caps. Pictures: Kenney "Input Prompts" (CC0).

WHEN SOMETHING GOES WRONG
- Plainer messages when your game is missing, is another game or another version, cannot be read, or the game
  stops (what happened and what to do next).
- After a crash that left a crash dump, "Save crash report" puts a zip on your desktop (crash dump, the game's
  log, your ini files; your user name and folders are removed from the text files). You send it yourself; the
  launcher sends nothing.

UPDATES
- Once a day the launcher can look up the newest release number on GitHub and say "A new version is available" with
  a button that opens the download page. Nothing is downloaded. It stays quiet offline, and there is an ON/OFF row
  on the Overview tab. See docs\NETWORK.md in the source release.

GAME (build c369)
- No console window opens when the game or the launcher starts.
- Button prompts now change the A/B/X/Y pictures inside the game too (Auto, Xbox, Original Xbox, PlayStation).
  The two picture packs ship in texturepacks\ (Kenney Input Prompts, CC0).
- capabilities.json tells the launcher which features this game build has.

KNOWN ISSUES
- Mechagodzilla 3's back missiles are invisible while they fly; the launch flash and the hits show.
- Patch mods are prepared but not yet loaded by the game. Work continues.

PACKAGE
- The download no longer contains the unused variable Pixelify Sans font file; every shipped font is credited
  in CREDITS.md. The Visual C++ runtime DLLs now come from the same Visual Studio version that built the launcher.
- miniz (MIT) is added for reading mod zips; see THIRD_PARTY_NOTICES.md.
