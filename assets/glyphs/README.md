# Controller glyphs (not added yet)

Planned source: Kenney "Input Prompts" (CC0, https://kenney.nl/assets/input-prompts). The zip can only be downloaded through a browser.

To add them: unzip into this folder, add the zip's SHA-256 to `CREDITS.md`, then tell the launcher session. The launcher will pick Xbox / PlayStation art from the "Button prompts" setting (Auto follows the connected controller; Original Xbox uses the Xbox art with "Black" and "White" for the shoulder buttons). Until the files are here, the hint bar and the remap screen use text key caps with the same naming.
